citation-topics

Research topics and broad areas for any list of works (papers, theses, projects, patents) from their citation links, with Leiden clustering of the direct-citation network as CWTS does for the OpenAlex topics; a board to explore them, and Claude skills that name them.

How the topics are madeThe Leiden algorithm explained step by step, and what the package does exactly. Sample boardThe citation community of INSPIRE-HEP author 991924: 1,967 works in 11 topics. The sample

The papers of the INSPIRE-HEP author 991924 together with every paper citing them, downloaded on 2026-11-15: 79 papers of the author and 1,888 citing papers, with 16,920 citation links among them. Made with:

pip install citation-topics
python inspire_profile.py 991924 works.jsonl     # examples/inspire_profile.py in the repository
citation-topics run works.jsonl out/ --resolution 1 --min-size 20 --seed 4
citation-topics describe works.jsonl out/ --abstracts
citation-topics names out/ names.json            # names written by Claude's topic-namer skill
citation-topics export out/ --works works.jsonl --highlight own --highlight-label "The author's papers"
citation-topics board works.jsonl out/ --highlight own --highlight-label "The author's papers" \
    --title "INSPIRE author 991924: citation topics" \
    --vosviewer-url https://restrepo.github.io/citation-topics/examples/inspire-991924/works_vosviewer.json

The files: names.json, works_vosviewer.json (works) and topics_vosviewer.json (topics), for VOSviewer Online or VOSviewer. A new download from INSPIRE-HEP gives slightly different numbers as new citing papers appear.

The board's Full INSPIRE tab compares its topics with those of the whole INSPIRE-HEP citation network (1.9 million papers, 304 topics, from restrepo/inspireauth10): python examples/full_inspire_tab.py docs/examples/inspire-991924 PATH_TO_INSPIREAUTH10.

The OpenAlex sample

The same path for any field, from an OpenAlex author profile: the works of the author A5010397600 (marine and coral-reef ecology) together with every work citing them, downloaded on 2026-11-16: 90 works of the author and 2,136 citing works, with 8,295 citation links among them, in 12 topics and 6 areas (resolution 1; seed 4 is the medoid of seeds 1 to 4, topic NMI 0.84). The smallest area holds the taxonomy papers that cite the author's Catalogue of Life. Made with:

python openalex_profile.py A5010397600 works.jsonl   # examples/openalex_profile.py in the repository
citation-topics run works.jsonl out/ --resolution 1 --min-size 20 --seed 4
citation-topics describe works.jsonl out/ --abstracts
citation-topics names out/ names.json
citation-topics export out/ --works works.jsonl --highlight own --highlight-label "The author's works"
citation-topics board works.jsonl out/ --highlight own --highlight-label "The author's works" \
    --title "OpenAlex author A5010397600: citation topics" \
    --vosviewer-url https://restrepo.github.io/citation-topics/examples/openalex-A5010397600/works_vosviewer.json

The script takes an OpenAlex author id or an ORCID and needs only the Python standard library; it works without an API key (set OPENALEX_API_KEY to use yours). Each work carries its OpenAlex field and subfield as categories, its authors' countries and its DOI as link. The files: names.json, works_vosviewer.json and topics_vosviewer.json.
